# Influenza 360° — Tahun 4

Laman pembelajaran interaktif Bahasa Melayu dengan tiga misi:
1. Mengenali influenza dan meneroka model virus 3D sebagai pengayaan.
2. Mengikuti penyebaran titisan dan memilih tindakan pencegahan.
3. Membezakan virus dengan bakteria melalui permainan kad.

## Fail laman
- `index.html`: halaman utama dan model 3D.
- `missions.js`: aktiviti, animasi titisan dan kemajuan misi.

Letakkan kedua-dua fail dalam direktori yang sama. Laman ini statik dan tidak memerlukan proses build. Sambungan internet diperlukan untuk pustaka Three.js daripada CDN. Kemajuan misi disimpan dalam sesi halaman sahaja.

## GitHub Pages
Terbitkan kandungan direktori ini sebagai akar laman. Halaman masuk ialah `index.html`.

## Penggunaan dalam Canva
Gunakan URL laman yang sudah diterbitkan sebagai pautan dalam reka bentuk. Interaksi memerlukan pelayar yang menjalankan JavaScript; eksport PDF atau imej tidak menjalankan simulasi.
